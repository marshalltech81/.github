# Support

Thanks for using and exploring these projects.

## How to get help

Use the following paths depending on what you need:

- **Questions and general help**: Use GitHub Discussions if available, or open a discussion in the
  appropriate community space.
- **Bug reports**: Open a GitHub issue using the bug report template.
- **Feature requests**: Open a GitHub issue using the feature request template.
- **Security vulnerabilities**: Do **not** open a public issue. Follow the instructions in `SECURITY.md`.

## Before opening an issue

Please:
- read the `README.md`
- check existing issues and discussions
- use the provided templates when available
- include enough detail for someone else to understand or reproduce the problem

## What to include

When asking for help, include:
- what you are trying to do
- what happened
- what you expected to happen
- steps to reproduce, if relevant
- version, environment, or commit details if known
- logs, screenshots, or error messages if helpful

## Response expectations

Support is provided on a best-effort basis.
Response times may vary depending on availability and project priorities.

## Scope

The following are generally a better fit elsewhere:
- **security reports** → `SECURITY.md`
- **code of conduct concerns** → `CODE_OF_CONDUCT.md`
- **funding and sponsorship** → GitHub Sponsors or the links in `FUNDING.yml`

## Thanks

Clear, focused reports and questions make support much easier.
