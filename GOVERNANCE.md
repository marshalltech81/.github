# Governance

## Project stewardship

This project is currently maintained by a single primary maintainer.

The maintainer is responsible for:
- setting project direction
- reviewing and merging changes
- managing releases
- making final decisions on scope, priorities, and repository policy

## Decision-making

This project uses a maintainer-led governance model.

Feedback, issues, pull requests, and proposals are welcome, but final decisions are made by the maintainer.

Decisions are generally based on:
- correctness
- security
- maintainability
- project scope
- long-term support burden
- alignment with the goals of the project

## Contributions and influence

Contributors are welcome to:
- report bugs
- suggest features
- improve documentation
- submit pull requests
- discuss tradeoffs and implementation approaches

Contributions are considered on their merits, but contribution does not automatically grant
decision-making authority, commit access, or maintainer status.

Over time, trusted contributors may be given additional responsibilities at the maintainer’s discretion.

## Maintainer responsibilities

The maintainer will make a reasonable effort to:
- review contributions in good faith
- communicate clearly about major decisions
- keep repository policies consistent
- document meaningful changes in direction when practical

The maintainer may decline changes that:
- significantly expand scope without clear need
- weaken security or maintainability
- conflict with the project’s goals
- duplicate existing or planned work

## Governance changes

This governance model may change as the project grows.

If the project gains additional maintainers or requires a more formal structure, this document may
be updated to reflect new roles, responsibilities, or decision-making processes.
